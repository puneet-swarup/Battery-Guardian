## Privacy Policy

This program will not transfer any information to other networked systems
unless specifically requested by the user or the person installing or operating
it, with the following exceptions:

- The application checks GitHub for updates (once every 24 hours). This sends
  only a standard HTTPS request to GitHub's public Releases API. No personal
  data is transmitted. See the [GitHub Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement).

The application does not collect telemetry, analytics, or usage data.
