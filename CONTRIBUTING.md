# Contributing to Battery Guardian

Thank you for your interest in contributing! 

## How to Contribute
1. Fork the repository.
2. Create a new branch for your feature (`git checkout -b feature/amazing-feature`).
3. Make your changes.
4. Commit your changes (`git commit -m 'Add some amazing feature'`).
5. Push to the branch (`git push origin feature/amazing-feature`).
6. Open a Pull Request against the `main` branch.

## Important Notes
- Please ensure your code builds successfully on Windows.
- Follow the existing coding style (no MVVM, simple and lightweight WPF).
- Any changes must pass the GitHub Actions build pipeline before merging.
